# 42 Advanced Curriculum

Personal workspace for my **42 Advanced Curriculum** projects.

After completing the 42 Common Core, I am using this repository to organize my advanced projects, document my learning path and build a stronger portfolio around backend development, infrastructure, data and systems programming.

This repository is intentionally a work in progress.

---

## Current Status

I am currently starting the Advanced Curriculum and using this repository as a structured workspace.

The goal is not only to complete projects, but also to document:

* what each project teaches
* why I selected it
* what technologies are involved
* what I learned
* how it connects to backend, systems or infrastructure work
* how it can be explained in interviews

---

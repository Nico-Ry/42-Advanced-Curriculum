# Advanced Curriculum Roadmap

This roadmap tracks my planned direction through the 42 Advanced Curriculum.

It is not a fixed plan. It will evolve depending on project availability, internship/job opportunities, technical interests and portfolio value.

---

## Goal

My main goal is to continue growing from Common Core foundations into stronger backend, infrastructure, data and systems skills.

I want this curriculum to help me build projects that are useful for:

* backend developer roles
* infrastructure and DevOps-oriented roles
* data/backend hybrid roles
* technical interviews
* long-term software engineering foundations

## Portfolio Strategy

Each completed project should include:

* clear README
* setup instructions
* explanation of the technical problem
* architecture notes
* what I learned
* screenshots or diagrams when useful
* interview talking points

The goal is not only to complete projects, but to make them understandable for recruiters, interviewers and other developers.

---

## Documentation Standard

Every project should eventually include:

```text
README.md
  ↓
Overview
  ↓
Tech stack
  ↓
How to run
  ↓
Architecture / implementation notes
  ↓
What I learned
  ↓
Possible improvements
```

Optional additions:

* screenshots
* diagrams
* test examples
* benchmark notes
* troubleshooting section
* links to related projects
